## Why this file exists

Every commit here shares one operator Git identity (`vaibhav4046 <115102797+vaibhav4046@users.noreply.github.com>`). Git authorship therefore cannot show which seat produced which change, and the participant guide is explicit that **the room event log is what shows the work was the band's**. This index is the machine-checkable bridge between the two.

## What it does and does not claim

- **Claims:** for each commit, the first agent `text`/`task` message that named that commit's SHA, which seat sent it, and when. A judge can re-derive this from `room.json`.

- **Does not claim:** that the announcing seat typed the code. `thought` messages (internal reasoning) and `tool_result` messages (echo of a shell command) are deliberately excluded, so a commit announced only inside a `tool_result` reads as *no room announcement* rather than being guessed at. Where the announcing seat names itself in the report it is marked `self`.

- **Limitation:** a coordinator relaying a seat's commit is recorded as announced-by-the-coordinator. Cross-check the `self` flag and `mentioned_by` column before drawing conclusions about who wrote what. `room.json` remains the authoritative record.
